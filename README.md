# AgriQueue a Smart Procurement Queue & Tracking System for Farmers

## Problem Statement
Farmers often face long waiting times, lack of information about procurement schedules, and uncertainty regarding procurement and payment status.

## Solution
A digital platform that enables farmer registration, slot booking, real-time queue management, notifications, and procurement/payment tracking.

## Features
- Farmer Registration
- Slot Booking
- Live Queue Tracking
- SMS/App Notifications
- Procurement Status Tracking
- Payment Status Updates

## Tech Stack
- React.js
- Node.js
- Express.js
- MongoDB
- Firebase/SMS Gateway
